## 📖 这是什么？

**Letit** 是一个把圣多纳释放法（Sedona Method）装进口袋的练习册。它不评判你、不催促你，只是陪你完成一件很简单的事：

> 觉察此刻的感受 → 允许它存在 → 放它走。

你可以用它释放一件被触发的小事，也可以围绕一个重要目标做深度练习，还可以让 AI 陪你一句一句地把感受松开。

所有数据都保存在你自己的手机里，没有账号、没有上传、没有广告。

## 📥 下载安装

📦 所有版本文件都在：[Releases · 最新版本](https://github.com/1Xxuan/letit/releases/latest)

### 方式一 · 安卓 / 鸿蒙手机：安装 APK（推荐）

1. 下载 `letit-vX.X.X.apk`
2. 点开安装，首次会提示"允许安装未知应用"，按提示允许即可
3. 装好后桌面出现图标，打开就是 App

| 系统 | 支持情况 |
|---|---|
| Android 7.0 及以上 | ✅ 直接安装 |
| 鸿蒙 HarmonyOS 2 ~ 4.X | ✅ 可安装 APK（兼容安卓应用） |
| 鸿蒙 HarmonyOS NEXT（5.0+ / 纯血鸿蒙） | ✅ 先装「卓易通」（华为应用市场可下载），通过卓易通安装和使用 APK |

🔄 **更新**：应用每次打开会自动检查新版本，弹窗点「去下载」即可，练习数据不会丢失。

### 方式二 · 任何手机 / 电脑：网页版 HTML

适合 iPhone、纯血鸿蒙，或不想装 App 的人。

1. 下载 `letit-vX.X.X.html`（约 12MB，**字体已内置**，单文件）
2. 传到手机后，在**文件管理器里用浏览器打开**：
   - iPhone：「文件」App 找到文件 → 长按 → 分享 → Safari
   - 安卓：文件管理器 → 选择"用浏览器打开"
3. 全部功能立即可用，界面字体与 App 完全一致

> ⚠️ **不要在微信里直接点开预览**——微信内置浏览器跑不起来，请用 Safari / Chrome / 系统浏览器打开本地文件。

✅ **长期稳定**：这是一个纯静态文件，不依赖任何服务器，存着永远能打开、断网也能用（AI 引导、在线语音、云同步这些需要联网的功能除外）。换浏览器、换设备，把文件复制过去照样用。

### 方式三 · 部署到公网（进阶）

如果你有自己的服务器、对象存储或虚拟主机，把单文件 HTML 直接上传，就得到一个网址——手机电脑浏览器都能访问，还可以"添加到主屏幕"，体验最接近原生 App，也省去传文件的麻烦。

### 方式四 · 第三方打包工具

小码盒、无思微程序等网页打包工具，可以把 HTML 包装成轻应用 / 小程序容器使用，适合想固定入口的用户，按各平台的接入说明操作即可。

## 🚀 使用说明

### 🏠 首页

- **每日语录**：每次打开随机一句，点「换一条」刷新，可固定喜欢的句子
- **连续天数**：记录你连续练习的日子，坚持看得见
- **今天被触发的主题**：练习里写下触发事件后，这里会出现快捷入口，点一下就能针对这个主题再深挖

### 🧘 练习（核心功能）

练习页有四个模块，按需选择：

<details>
<summary><b>陪练引擎</b> —— 标准引导流程（推荐从这里开始）</summary>

1. **写下触动事件**：什么事让你有了感觉？
2. **识别感受**：从情绪里认出此刻的状态（不确定也没关系，流程会带你）
3. **三问句循环**：
   - 你能让它离开吗？
   - 你愿意让它离开吗？
   - 什么时候？
4. **无论答案是能还是不能**，继续下一轮就好——释放不靠用力
5. **结束记录**：给轻松度打个分，写一句变化（也可以跳过备注，练习照样计数）

走不动的时候，引擎会自动切换策略：深层阻抗、安全阀、换个问法……你只管跟着走。

</details>

<details>
<summary><b>目标释放</b> —— 围绕一个重要目标做深度清理</summary>

1. 写下你的目标（比如"今年当上主管"）
2. 应用自动识别主题分类（AI 在线时会判断得更准，分类可以手动点选修正）
3. 跟着主题问句，释放对目标的抓取与恐惧
4. **翻面 → 行动步骤**：写下你认为"必须做"的事，逐条释放背后的阻力
5. 完成后可在目标页持续**跟踪**：记录显化观察，回看它是否在靠近

</details>

<details>
<summary><b>根本欲望识别</b></summary>

直接往深挖一层：这件事背后，是想要<b>被认同</b>、想要<b>控制</b>，还是想要<b>安全</b>？

三大想要是所有感受的地基。放下对它们的执着，想要的一切会自然发生。

</details>

<details>
<summary><b>AI 引导</b> —— 让 AI 陪你一句一句释放</summary>

配置自己的 AI 后（[见下方配置指南](#-ai-引导配置)），你会得到一个 24 小时在线的引导师：

- **温柔拆解**风格：先接住情绪，再拆解信念，引用莱斯特的话，落回释放
- **简单直接**风格：不铺垫，直问想要——「目标必须实现，这是想要控制，对吗？」
- 发现限制性信念时自动生成**信念卡片**，点「带我释放它」直接进入释放流程
- 练习中随时点「✦ 让 AI 贴合我换个问法」，AI 会把标准问句改写成贴合你目标的版本

</details>

### 📔 记录

- **收获本**：每次完成练习的记录都在这里，看到自己的变化轨迹
- **速查**：
  - 情绪释放三问句速查
  - 欲望释放速查
  - 卡住时怎么办
  - **情绪层级完整表**（AGFLAPCAP 中英对照，414 个情绪词，点击层级展开）

### 🎯 目标跟踪

在目标页添加目标后，可以记录"此刻的感受"和"行动步骤"，持续跟踪它们被释放的进度。当目标相关的显化出现时（生活中注意到的变化），记一条**显化观察**——这是假设法则落地的证据链。

### ⚙️ 设置

- **AI 引导**：服务商预设 / 接口地址 / 模型 / API Key / 风格 / 附加提示词
- **语音朗读**：系统内置 TTS（免费离线）/ SiliconFlow / Qwen TTS / Kokoro 本地部署 / 讯飞
- **释放问句包**：内置五类问句，可自定义分类、增减问句、导入导出分享
- **数据管理**：导出 / 导入全部数据（JSON）、云同步（WebDAV·坚果云 / S3）、清除数据
- **应用更新**：显示当前版本，手动检查更新（打开应用时也会自动检查）

## 🤖 AI 引导配置

1. 打开 **设置 → AI 引导**
2. **服务商预设**里选一家（DeepSeek / 智谱 / Moonshot / SiliconFlow / Qwen / 讯飞 / OpenAI 兼容地址均可）
3. 填入你的 **API Key**（在各服务商官网注册后创建，与应用无任何绑定关系）
4. 给 AI 起个名字，选好引导风格，保存

> 💡 **没有 Key？** 推荐从 DeepSeek 开始，注册即送额度，成本低。
>
> 🔒 Key 只保存在你设备本地，不会上传到任何服务器。没有配置 AI 时，除 AI 引导外的全部功能照常可用。

## ☁️ 数据安全

- 所有练习数据默认**只存在本机**
- 担心丢失？两种方式保护：
  1. **设置 → 数据管理 → 导出所有数据**，定期导出 JSON 文件保存
  2. **云同步备份**：填入你的坚果云 WebDAV 或任意 S3 兼容存储，自动定时上传

## ❓ 常见问题

<details>
<summary><b>要付费吗？需要注册账号吗？</b></summary>

应用完全免费、无广告、无需注册。唯一可能的花费是你自己配置的 AI 服务（用你自己的 API Key，按服务商标准计费，通常很低）——不配置 AI 也完全可以正常使用。
</details>

<details>
<summary><b>我的练习数据安全吗？会上传到哪里吗？</b></summary>

所有数据只存在你自己的设备里，应用没有后台服务器，不收集任何信息。除非你主动开启云同步（上传到<b>你自己填写</b>的坚果云 / S3）或导出分享，数据不会离开手机。AI 对话的内容也只发送给你自己配置的服务商。
</details>

<details>
<summary><b>更新之后，练习记录会丢吗？</b></summary>

不会。覆盖安装会保留全部本地数据。不过"设置 → 数据管理 → 导出所有数据"的定期备份习惯永远值得养成——手机丢了、换机了，一份 JSON 就能完整恢复。
</details>

<details>
<summary><b>我什么感觉都没有，是不是用法不对？</b></summary>

恰恰相反——"没感觉"是释放法里非常经典的一层（万念俱灰层）。应用为此内置了专门的「没什么感受」问句包和处理路径：如实写下"没什么感受"开始练习就好，不需要刻意制造情绪，也不需要"先让自己有感觉"。
</details>

<details>
<summary><b>在微信里点开 HTML 没反应？</b></summary>

微信内置浏览器不支持打开本地 HTML 文件。正确做法：收到文件后点右上角「…」→ 选择「用其他应用打开」→ Safari / 系统 browser；或者把文件存到「文件」App 里再打开。
</details>

<details>
<summary><b>这和宗教、心理治疗有关系吗？</b></summary>

没有宗教属性。圣多纳释放法是一套自我情绪觉察与放下的练习方法，人人可以自行使用。它不能替代心理治疗——如果你正处于严重而持续的情绪困扰中，请优先寻求专业帮助。
</details>

## 🛠 从源码构建

需要：Node.js、JDK 17+、Android SDK（platform 36 / build-tools 35+）。

```bat
git clone https://github.com/1Xxuan/letit.git
cd letit
npm install
copy index5.0.html www\index.html
npx cap sync android
cd android && gradlew.bat assembleDebug
```

产物：`android\app\build\outputs\apk\debug\app-debug.apk`

核心应用是一个单文件 Web 应用（`index5.0.html`），理论上任何现代浏览器打开即可运行。
