## Usage

### iOS
Copy the `AppIcon.appiconset` folder to your Xcode project's Assets.xcassets.

### Android
Copy the contents of `res/` to your `app/src/main/res/` folder.

### Web
Copy the files to your public folder and add the HTML from `favicon-html.txt` to your `<head>`.

### Original Icon
Use `original/icon-1024.png` for the original high-quality icon image.
